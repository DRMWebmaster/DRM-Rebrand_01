DRM Rebranding Phase One · v1.1

Website Design Standards

Working implementation notes for translating our GitHub prototypes into Denver Rescue Mission's WordPress/Kadence website. These are recommendations, not changes to the live WordPress theme.

Content widths

LayoutRecommended maximumUse
Normal1,170pxDefault content sections and common two-column layouts
Wide1,280pxCards, strategy layouts and expansive content sections
Full width100%Edge-to-edge backgrounds, hero sections and banners

The prototypes use several nearby container sizes—commonly 1,170px, 1,180px and 1,240px. The recommended normal and wide values simplify those into a consistent WordPress system.

Keep long-form text blocks around 750–850px maximum for comfortable reading, even when the containing row is wider.

:root {
  --content-width: 1170px;
  --wide-width: 1280px;
}

These are illustrative variables; map the widths into the actual Kadence theme configuration rather than assuming these variable names already exist.

Keep navigation, form labels and minor utility text smaller. Use mobile-friendly gutters and responsive columns.

Color guidance

Blueberry #202945 is the dominant theme. Water #62B1BD is a regular button color, with Blueberry hover states. Banana #FFC845 is an accent, paired with Blueberry text. Light Oatmeal #F3F1EF softens content backgrounds. DRM Red #862633 is used selectively. Avoid widespread Pumpkin/orange and Bell Pepper/green usage. Keep all five strategy sections within a Blueberry-based identity.

Content architecture: strategies, programs and help

Five core strategies: Dignity, Readiness, Recovery, Housing, and Prevention. These describe interconnected ways DRM helps people move toward stability, not five exclusive program categories. Do not assign every program to one strategy or imply strategies operate in a fixed sequence.

StrategyEditorial meaning
DignityRespect and compassionate treatment throughout every program and service.
ReadinessBuilding practical skills and readiness for employment, relationships, and independent life where appropriate.
RecoverySupporting recovery from addiction and related barriers as relevant to individual participants.
HousingHelping people find and maintain stable housing; do not imply DRM currently owns or operates permanent housing as part of this strategy.
PreventionHelping avert homelessness before it occurs; distinguish the broad strategy from the specific Prevention Program.

Programs describe actual services offered. On program pages, explain how multiple relevant strategies work together, without requiring five identical sections on every page. Use approved descriptions, eligibility, and current program names.

Get Help is the exception to strategy-led navigation. Organize it by the person's needs, with direct pathways to shelter, meals, family assistance, recovery help, housing support and essentials. Use plain-language headings first and official program names second. Confirm eligibility, location, intake steps and contact information against the live source before publishing.

Legacy model: Emergency Services, Rehabilitation, Transitional Programs and Community Outreach are the former four strategies. Replace strategy-level references with the new five, but preserve historical quotations and documents accurately. Never simply rename a program based on its former category.

Migration notes

Update WordPress container settings and reusable Kadence row layouts first, then apply typography and colors, and finally review pages on mobile and desktop. The prototype newsletter bar is visual only; the production version needs a connected subscription form. The screenshot footer is a visual reference and should be replaced with accessible, functional WordPress footer elements for production.
